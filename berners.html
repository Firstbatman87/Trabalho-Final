Criador da World Wide Web

"A web conecta pessoas, ideias e conhecimentos."

Biografia

Timothy John Berners-Lee é um físico e cientista da computação britânico, responsável por inventar a World Wide Web em 1989 enquanto trabalhava no CERN. Ele criou as tecnologias fundamentais que permitem navegar na internet até hoje.

Frase que o define: “O homem que decidiu dar a Web de presente ao mundo de forma gratuita e descentralizada.”

Linha do Tempo

1955

Nascimento em Londres: Timothy John Berners-Lee nasceu em 8 de junho de 1955.

1980

Desenvolvimento do ENQUIRE: Criou um programa para estabelecer conexões entre documentos no CERN.

1989

Proposta da Web: Apresentou o projeto para um sistema universal de informações via hipertexto.

1990

Primeiro Servidor e Navegador: Criou o navegador WorldWideWeb e definiu HTML, HTTP e URL.

1993

Domínio Público: O CERN disponibilizou o código da Web gratuitamente, sem cobrança de royalties.

1994

Fundação do W3C: Fundou o World Wide Web Consortium para estabelecer padrões abertos para a Web.
