Tim Berners-Lee

Criador da World Wide Web

"A web conecta pessoas, ideias e conhecimentos."

Biografia

Tim Berners-Lee é o cientista da computação que inventou a World Wide Web em 1989, enquanto trabalhava no CERN. Sua criação possibilitou conectar documentos por meio de links e facilitou o compartilhamento de informações pela Internet.

Frase que o define: “O cientista que transformou a maneira como as pessoas acessam e compartilham informações no mundo.”

O mundo da tecnologia antes de suas contribuições

Entre as décadas de 1970 e 1990, a computação passou por grandes transformações. Os computadores começaram a chegar também às residências e a pequenos negócios. Apesar desses avanços, a tecnologia ainda apresentava limitações importantes.

A Internet já existia antes, mas a existência de uma rede mundial não significava facilidade para navegar entre páginas. Foi nesse cenário que Tim criou a World Wide Web, um sistema para conectar e acessar informações facilmente.

Como era a comunicação entre computadores?

Antes da Web, a troca de informações dependia de ferramentas distintas (como e-mail e FTP). Não existia um sistema de uso geral com documentos interligados por links.

O nascimento da World Wide Web

Em março de 1989, Tim apresentou a proposta no CERN. Em 1990, ele implementou três tecnologias fundamentais:

  • HTML: linguagem utilizada para estruturar documentos da Web.
  • HTTP: protocolo de comunicação entre clientes e servidores web.
  • URL: sistema de endereçamento para identificar recursos.

Linha do Tempo de Tim Berners-Lee

1955

Nascimento em Londres: Timothy John Berners-Lee nasceu em 8 de junho de 1955. Estudou física na Universidade de Oxford.

1980

Desenvolvimento do ENQUIRE: Criou um programa experimental para estabelecer ligações entre informações no CERN.

1989

Proposta da World Wide Web: Apresentou o projeto para um sistema de gerenciamento de informações baseado em hipertexto.

1990

Primeiro navegador e servidor Web: Criou o navegador WorldWideWeb e estabeleceu as bases de HTML, HTTP e URL.

1991

Divulgação da Web: O software da Web foi disponibilizado para uso fora do CERN.

1993

Domínio Público: O CERN disponibilizou o software da Web em domínio público, sem cobrança de royalties.

1994

Fundação do W3C: Criou o World Wide Web Consortium para estabelecer padrões universais para a Web.

Contribuições e Projetos

1. World Wide Web (WWW)

Permite acessar páginas e navegar por links. A Web não é a mesma coisa que a Internet: a Internet é a infraestrutura física de computadores, e a Web é o sistema de páginas que roda sobre ela.

2. HTML

Linguagem de marcação para estruturar o conteúdo das páginas web.

3. HTTP

Protocolo de comunicação que define as regras de troca de dados na Web.

4. URL

Sistema de endereçamento único para localizar qualquer documento na rede.

5. W3C (World Wide Web Consortium)

Organização que garante que os sites funcionem em qualquer navegador ou celular.

Desafios e Obstáculos

1. Convencer outras pessoas a apoiar a ideia

Sua primeira proposta no CERN foi classificada pelo seu chefe como apenas "vaga, mas empolgante".

2. Dificuldade de acesso inicial

O primeiro navegador só funcionava em computadores NeXT, que eram caros e raros na época.

3. Liberar e espalhar a Web

Garantir que a Web se tornasse livre e de domínio público em 1993, evitando que uma única empresa a monopolizasse.

O Legado no Dia a Dia

  • Navegadores: Chrome, Edge e Firefox usam as tecnologias criadas por Tim.
  • Links: Clicar em qualquer link para trocar de página é a ideia original da Web de 1989.
  • Padronização: Garantia de que um site abra bem tanto no computador quanto no celular.
